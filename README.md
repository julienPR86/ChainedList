# My simple linked list library

## Description

This is a simple linked list library that I use in my personal projects.

## Instructions

To use this lib, you can add the header in the necessary files, and add `#define LIBLLIST_IMPLEMENTATION` in **only one** of them to get access to the function definitions.

It should look something like:

```c
#define LIBLLIST_IMPLEMENTATION
#include "libllist.h"
```
